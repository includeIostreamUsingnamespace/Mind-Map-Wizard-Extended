This is an extended version of [Mind Map Wizard](https://mindmapwizard.com) with added AI-powered features.

## What Was Added

Right-click on any mind map node to access AI features:

- **AI Brainstorm** — Generate 5-8 creative sub-topics
- **AI Research** — Generate structured research information
- **AI Explain** — Explain concepts in simple terms
- **AI Polish** — Improve text clarity and professionalism
- **AI Summarize** — Summarize branch content
- **AI Restructure** — Reorganize sub-nodes by logical groups
